# الأدوار والصلاحيات في نظام الموارد البشرية

هذا الجدول يصف الصلاحيات الحالية. نتائج القبول والنشر المحلي والاختبارات موثقة في [تقرير القبول](ACCEPTANCE_AR.md). دليل الموقع يعرض خطوات خاصة بالدور، وصفحة ملفي الشخصي تعرض بيانات صاحب الجلسة فقط.

## معنى الدور والمسمّى

الدور يحدد ما يستطيع حساب الدخول فعله. المسمّى الوظيفي يصف وظيفة الموظف داخل المؤسسة، ولا يمنح صلاحيات. تعيين موظف مديرًا للقسم في بيانات القسم لا يضيف دور مدير القسم تلقائيًا؛ يجب ربط حسابه بالموظف وإسناد الدور أيضًا.

إذا جُمعت عدة أدوار في حساب واحد، تُجمع الصلاحيات الممنوحة له؛ الجداول التالية تفترض دورًا واحدًا لكل حساب كما هو الحال في الحسابات الحالية.

الموارد البشرية ومسؤول النظام يمتلكون صلاحية المراجعة على نطاق المؤسسة. المنع الصريح لاعتماد الطلب الشخصي يخص مدير القسم عندما لا يملك دور موارد بشرية أو مسؤول نظام. هذا وصف للقواعد الحالية وليس افتراضًا بوجود فصل موافقات إضافي.

تقديم طلب معلّق يحجز أيامًا من المتبقي. الموافقة تحولها من محجوزة إلى مستخدمة دون خصم ثانٍ، والرفض أو إلغاء الطلب المعلّق يحرران الحجز. الرصيد محسوب من حالات الطلبات المحفوظة، ويقسَّم الطلب الممتد بين سنتين على السنتين. اختيار الحالة في التقرير يفلتر الطلبات فقط؛ جدول الرصيد يحسب جميع طلبات السنة المختارة. الحساب بالأيام التقويمية مع شمول يوم البداية والنهاية؛ لا يوجد تحويل تلقائي للساعات أو استبعاد تلقائي للعطل. الرصيد المتبقي المعروض لا يقل عن صفر؛ وجود عداد لا يعني وجود منع آلي لتجاوز الرصيد في خدمة تقديم الطلب الحالية.

| العملية | الأدوار المسموحة |

## طريقة العمل المختصرة لكل دور

| الدور | تسلسل العمل المعتاد | ما يُحال لدور آخر |
|---|---|---|
| مسؤول النظام | تجهيز الأقسام والمسميات ← إدارة الموظفين ← إنشاء الحسابات وربطها ← ضبط أنواع الإجازة ← متابعة الطلبات والدوام والتقارير والتدقيق | السياسات المؤسسية تحدد طريقة الاعتماد؛ الحساب لا يقررها تلقائيًا |
| مدير الموارد البشرية | إدارة المؤسسة والموظفين ← متابعة الدوام وتصحيحه ← مراجعة الإجازات ← التقارير والتدقيق | حسابات الدخول والأدوار وإعادة تعيين كلمات مرور الآخرين لمسؤول النظام |
| مسؤول الموارد البشرية | الموظفون ← متابعة الحضور وتصحيحه ← مراجعة الإجازات ← التقارير | تعديل الأقسام والمسميات وأنواع الإجازة لمدير الموارد البشرية؛ الحسابات لمسؤول النظام |
| مدير القسم | حضور شخصي ← طلبات القسم المعلقة ← الموافقة أو الرفض ← تقارير القسم ← تقرير إجازاته | طلبه الشخصي وتصحيح الدوام للموارد البشرية؛ الحسابات لمسؤول النظام |
| الموظف | حضور ← انصراف ← طلب إجازة عند الحاجة ← متابعة الطلب أو إلغائه إن كان معلّقًا ← تقرير إجازاتي | تصحيح الحضور وقرارات الإجازة للموارد البشرية أو المدير؛ الحساب لمسؤول النظام |
| المدقق | التقارير ← الفلترة ومراجعة النتائج ← سجل التدقيق ومراجعة العمليات | أي تعديل يُطلب من الدور المخوّل؛ لا ينفذه المدقق |

## استخدام تصحيح الدوام

1. ادخل بمسؤول النظام أو مدير الموارد البشرية أو مسؤول الموارد البشرية.
2. افتح الحضور وحدد الموظف والتاريخ.
3. اضغط «تعديل» بجانب الفترة المطلوبة، خصوصًا عند وجود أكثر من فترة في اليوم.
4. الموظف وتاريخ الدوام يبقيان محددين للفترة المفتوحة. عدّل وقت الحضور والانصراف والحالة والملاحظة.
5. اترك تاريخ الانصراف فارغًا لاستخدام تاريخ الدوام، أو اختر تاريخ اليوم التالي للوردية الليلية.
6. يجب وجود حضور قبل الانصراف، وألا تكون الأوقات مستقبلية أو الفترة أطول من 24 ساعة أو متداخلة مع فترة أخرى.
7. احفظ. الإجراء يسجل التغيير في التدقيق. لإضافة سجل مفقود استخدم زر تصحيح الحضور العام؛ عند تعدد السجلات في التاريخ نفسه اختر الفترة من الجدول.

## تصدير التقارير — تحديث ١٩ تشرين الأول
تنزيل PDF وإكسل يتبع صلاحية قراءة التقرير نفسها. مدير القسم يصدّر نطاق قسمه فقط، والموظف يصدّر تقرير إجازاته الشخصي فقط. صاحب صلاحية التدقيق يستطيع تصدير سجل التدقيق. الملف يشمل النتائج المطابقة للفلاتر المطبقة، ولا يفتح الوصول إلى صفحات أو موظفين آخرين. إدارة أنواع الإجازة أصبحت تعديل أيام وتفعيل السنوية والمرضية وبدون راتب فقط، دون إضافة نوع رابع أو مغادرة بالساعة.
