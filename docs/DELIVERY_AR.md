# تسليم مشروع HRMS

اعتمد المالك ASP.NET Core على .NET 8. راجع [تقرير القبول الحالي](ACCEPTANCE_AR.md) بدل نتائج الإصلاح القديمة.

أُضيف الملف الشخصي، وفُصل تنسيق العمليات في Application عن EF وSQL وIdentity في Infrastructure، وحُدثت السياسات والتوثيق. الواجهة تدعم العربية والإنجليزية وأجاكس وقائمة تُفتح بزر الثلاث خطوط وتقارير وصلاحيات الأدوار الستة.

نسخة النشر في artifacts/publish، والتحقق الكامل بالأمر scripts/verify-published.ps1. التجربة تشمل Production عبر HTTPS محليًا؛ لا يوجد ادعاء بإنشاء موقع IIS أو استضافة عامة.

المصدر مُجهز في Git محليًا. GitHub مؤجل حسب طلب المالك. لا توجد كلمات مرور مضمّنة؛ تبقى الأسرار محلية. بيانات HRMSnew محفوظة، والاختبارات تستخدم قواعد مؤقتة.
