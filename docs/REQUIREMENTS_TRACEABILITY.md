# مطابقة المتطلبات والأدلة الحالية

> تحديث ١٩ تشرين الأول: [طلبات المدرب والتصدير وسياسة الإجازة المبسطة](TRAINER_UPDATE_2026_10_19_AR.md) يتقدم على وصف النطاق السابق: PDF وإكسل مطلوبان، والإجازات سنوية ومرضية وبدون راتب وبالتواريخ فقط.

> المرجع الأحدث للحكم على المطابقة هو [المراجعة التفصيلية](PDF_DETAILED_REVIEW_AR.md). وجود تنفيذ أو نجاح الاختبارات لا يغلق البنود الجزئية والسياسات التي تنتظر اعتماد المدرب.

المرجع: HRMS_Software_Requirements.pdf، الإصدار 1.0 بتاريخ 11 تشرين الأول 2026. اعتمد المالك .NET 8 صراحة في 15 تشرين الأول 2026، ضمن بند الإصدار البديل المتفق عليه. GitHub مؤجل بطلب المالك.

| المتطلب | التنفيذ والدليل |
|---|---|
| FR-01 الهوية والصلاحيات | ستة أدوار، Identity حقيقي، ربط الموظف، تعطيل الحساب، منع دخول المحذوف وغير النشط، تغيير كلمة المرور واستعادتها؛ دخول فعلي بالأدوار الستة وحدود الصفحات. |
| FR-02 الموظفون | إنشاء وتعديل وبحث وفلترة وفرز وصفحات وحذف منطقي واستعادة وتزامن؛ ملفي الشخصي يُحدد من الجلسة. اختبارات SQL ودخول ومتصفح. |
| FR-03 الأقسام | إنشاء وتعديل وتفعيل وتعطيل ومدير نشط من نفس القسم وعرض موظفيه؛ لا يوجد حذف مادي من الواجهة. |
| FR-04 المسميات | رمز فريد ووصف ودرجة وقسم وحالة، مع حفظ المراجع وتدقيق التغيير؛ اختبار فهرس SQL. |
| FR-05 الحضور | توقيت الأردن وتخزين UTC وعدة فترات يوميًا وفترة مفتوحة واحدة وانصراف ليلي وتصحيح فترة وتدقيق؛ اختبارات SQL ومتصفح. |
| FR-06 الإجازة | أنواع وتواريخ وسبب ومراجعة وتعليقات ومنع التداخل والتكرار، أوقات اختيارية وحجز رصيد وتثبيته أو إعادته؛ اختبارات SQL ونماذج ومتصفح. |
| FR-07 التقارير | ملخص وموظفون وحضور وإجازات وقرارات وأعداد وتقرير إجازاتي، مع نطاق المدير والموظف؛ المؤشرات في POLICIES.md. |
| FR-08 التدقيق | تغييرات المؤسسة والموظفين والطلبات والتصحيح والحسابات والأمان، مع حفظ المعاملة وسجلها ومنع تعديل التدقيق داخل التطبيق. صلاحيات قاعدة الإنتاج جزء من الاستضافة. |
| FR-09 الحذف | استبعاد المحذوفين، استعادة محكومة، بقاء الأرقام محجوزة، تدقيق واختبارات SQL. |
| FR-10 اللغات | موارد عربية وإنجليزية واتجاهان وUnicode؛ تحقق متصفح للأدوار الستة في اللغتين وحجمَي الشاشة. |
| FR-11 الواجهات | API بإصدار وصلاحيات وCSRF وتحقق وصفحات وأخطاء وSwagger في التطوير؛ مزوّد خارجي واختبار الفشل والمهلة. |
| المعمارية | تنسيق العمليات في Application؛ EF وSQL وIdentity في Infrastructure عبر عقود داخلية. القراءة عبر الوحدات منفصلة وغير متتبعة، والربط عبر عقد صريح. |
| التشغيل والنشر | نسخة publish مستقلة وتشغيل Production محلي عبر HTTPS في Kestrel ومتصفح حقيقي. لا يوجد ادعاء باستضافة عامة أو IIS مثبت. |
| التسليم | مصدر ومهاجرات ومخطط علاقات وREADME وأدلة API وأدوار وسياسات ونشر واختبارات وبيانات محلية؛ Git محلي، وGitHub مؤجل بطلب المالك. |

الصور والمرفقات و2FA والتصدير اختيارية وليست نواقص إلزامية. التراكم والترحيل والعطل والإجازة الجزئية مشروطة بسياسة المؤسسة؛ لم تُفرض سياسة مؤسسية أو قانونية مفترضة. القيم المحلية موثقة والحساب بالأيام التقويمية.

راجع ACCEPTANCE_AR.md وVERIFICATION.md للنتائج وحدودها. نجاح الاختبارات دليل على السيناريوهات المسماة، وليس إثباتًا لكل إدخال ممكن أو شهادة أمنية مستقلة.
راجع [المراجعة المباشرة للـPDF والتعديلات](PDF_CHANGE_AUDIT_AR.md): العدد ٦ ليس شرطًا في الملف، لكن التنفيذ داخل SQL شرط صريح؛ جرى تصحيح القوائم وتوثيق بقية الفروق والسياسات المشروطة بدل اعتبار نجاح الاختبارات إثباتًا شاملًا.
