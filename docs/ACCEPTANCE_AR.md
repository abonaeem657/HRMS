# تقرير إغلاق الملاحظات وتسليم .NET 8

تاريخ المراجعة: ١٥ تشرين الأول ٢٠٢٦. المرجع هو HRMS_Software_Requirements.pdf الإصدار 1.0. اعتمد المالك ASP.NET Core على .NET 8 بدل الترقية إلى .NET 10، وأجّل GitHub إلى وقت لاحق.

## البنود التي أُنجزت

| البند | التنفيذ الحالي | الدليل |
|---|---|---|
| الملف الشخصي للموظف | صفحة «ملفي الشخصي» للعرض فقط، تستخرج السجل من صاحب الجلسة وتتجاهل أي رقم موظف في الرابط | اختبار ملكية السجل ودخول فعلي ومتصفح للأدوار الستة |

| حفظ تصحيح الدوام المتزامن | النموذج يحمل نسخة السجل الأصلية، ويُرفض الحفظ القديم أو المفقود عند تعديل فترة موجودة | اختبار حفظ صحيح ثم رفض نسخة قديمة، وتجربة تصحيح من المتصفح |

## الاختبارات النهائية

| المجموعة | ناجح | فاشل | متجاوز |
|---|---:|---:|---:|
| الوحدات | 35 | 0 | 0 |
| المعمارية | 7 | 0 | 0 |
| التكامل وSQL وHTTP والمتصفح | 38 | 0 | 0 |
| المجموع | 80 | 0 | 0 |

نتائج TRX موجودة محليًا داخل artifacts/test-results. يمكن إعادة النشر والتحقق من مجلد الحل:

~~~powershell
powershell -ExecutionPolicy Bypass -File scripts/verify-published.ps1
~~~

الاختبار يحتاج LocalDB أو خادم اختبار SQL وChrome. يقبل البرنامج النصي المسارين البديلين بالمعاملين TestSqlServer وChromePath. يُنشئ قواعد اختبار مستقلة ويحذفها بعد الانتهاء. لم تُضف هذه الجولة سجلات حضور أو إجازات أو حسابات إلى HRMSnew، ولم تغيّر كلمات مرورها. نجاح الدخول في الاختبارات يخص الحسابات المؤقتة ذات كلمات المرور المولّدة، وليس كلمات مرور حسابات المستخدم الحالية غير المتاحة محليًا.

## ملفات التسليم المحلية

- artifacts/publish: ملفات تشغيل التطبيق المنشور.
- artifacts/HRMS-net8-publish.zip: حزمة النشر.
- artifacts/HRMS-net8-source.zip: المصدر الموثق دون أسرار أو مخلفات البناء.
- artifacts/HRMS-source.bundle: نسخة Git محلية قابلة للاستنساخ لاحقًا.
- artifacts/HRMS-net8-migrations.sql: نص مهاجرات قابل لإعادة التنفيذ للمراجعة، وليس أمرًا بحذف قاعدة البيانات.
- artifacts/SHA256SUMS.txt: بصمات حزم التسليم.

إضافة الملف الشخصي وفصل الطبقات ونسخة تصحيح الدوام لا تغيّر مخطط قاعدة البيانات، ولا تحتاج مهاجرة جديدة على HRMSnew.

## حدود التسليم الحالية

التشغيل المنشور جُرّب محليًا في Production وHTTPS؛ لم يُنشأ موقع IIS أو عنوان عام على الإنترنت. اختيار الخادم وDNS والشهادة الموثوقة وصلاحيات قاعدة الإنتاج والنسخ الاحتياطي والمراقبة تخص الاستضافة الفعلية عند تحديدها. رفع GitHub مؤجل صراحة بطلب المالك.

الصور والمرفقات و2FA والتصدير اختيارية وفق المواصفات. قواعد تراكم الإجازات وترحيلها والعطل والأجزاء اليومية مشروطة بسياسة المؤسسة؛ النظام الحالي موثق بالأيام التقويمية، وأوقات الطلب اختيارية وليست إجازة بالساعة. لا يُفرض نظام رواتب أو سياسة قانونية مفترضة.
