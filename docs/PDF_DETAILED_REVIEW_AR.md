# مراجعة تفصيلية لمتطلبات ملف المواصفات

تاريخ المراجعة: ١٥ تشرين الأول ٢٠٢٦. المرجع: **HRMS_Software_Requirements.pdf، الإصدار 1.0، ٢١ صفحة**.

بصمة المرجع SHA-256: `37EBBC25577196A40B932BE5FA1FB7607DCE57B5F4D8D8468E79D734E4115933`.

هذه مراجعة تنفيذ وأدلة، وليست شهادة مطابقة كاملة. بقاء بند غير محسوم يمنع وصف المشروع بأنه مطابق لكل الشروط. نجاح الاختبارات لا يثبت تلقائيًا كل المتطلبات أو كل المدخلات الممكنة.

## طريقة قراءة النتائج

- **مطبق**: يوجد تنفيذ محدد؛ نوع التحقق مذكور في عمود الدليل. مراجعة الكود لا تعني تجربة كل حالة في المتصفح.
- **جزئي**: يوجد جزء من المتطلب، لكن تفسيره الحرفي أو إثباته غير مكتمل.
- **بانتظار اعتماد**: يحتاج قرارًا مؤسسيًا أو اختيار بيئة التسليم؛ لا يجوز اختراع السياسة واعتبارها معتمدة.
- **اختياري**: الملف نفسه يجعله اختياريًا أو مشروطًا بنطاق متفق عليه.
- **غير مثبت**: لا تتوفر أدلة كافية؛ لا يُحتسب نجاحًا.

الفهرس [PDF_REQUIREMENT_INDEX.csv](PDF_REQUIREMENT_INDEX.csv) يحفظ البنود القائمية بنص المرجع الإنجليزي ورقم الصفحة والسطر؛ هو جرد للمصدر، وليس تحويلًا آليًا لكل بند إلى «ناجح». الفقرات، والجداول، والشروط المتكررة في القبول تُراجع في الأقسام أدناه. تبقى الصياغة الأصلية في الـPDF هي المرجع عند اختلاف التفسير.

## الفجوات التي تمنع إعلان «مطابق ١٠٠٪»

١. اعتماد المدرب للسياسات، وتحديد هل يريد تاريخ تعيينات/انتقالات أو موافقًا مسبقًا أو عدة وظائف/مديرين.
٢. تأكيد معنى Delete للأقسام والمسميات مقابل التعطيل الحالي. لا يوجد حذف لهما؛ لن نضيف محو بيانات ونعتبره مطلوبًا من تلقاء أنفسنا.
٣. GitHub المؤجل، والاستضافة النهائية وصلاحيات قاعدة الإنتاج والشهادات ومفاتيح Data Protection والنسخ والمراقبة.
٤. عرض المدرب واعتماد القبول النهائي. لا يثبت نجاح التشغيل المحلي حصول هذا الاعتماد.

لا توجد نسبة مطابقة عددية في هذا التقرير؛ عدّ البنود المكررة أو الاختيارية قد يعطي نسبة مضللة. الأولوية لإغلاق كل بند إلزامي مع دليل مناسب، وتسجيل أي تغيير نطاق صريح.

## إعادة التحقق

من مجلد الحل:

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-published.ps1
dotnet list HRMS.sln package --vulnerable --include-transitive
~~~

نتائج الاختبار في `artifacts/test-results` بصيغة TRX. الاختبارات تعمل على قواعد مؤقتة وحسابات مولدة للاختبار؛ لا دليل هنا على معرفة كلمات مرور حسابات HRMSnew أو إعادة ضبطها. أعد تشغيل تطبيق Visual Studio ليرى تغييرات الكود.
