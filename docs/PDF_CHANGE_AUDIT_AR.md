## أمور تتطلب اتفاقًا ولا توجد في PDF قيمة نعيدها إليها

- إصدار المنصة: الصفحة 3 تسمح بـ.NET 10 أو إصدار آخر متفق عليه ومدعوم. أبقينا .NET 8 بطلب المالك؛ يُثبت قبول المدرب لهذا الاختيار عند التسليم.
- الدوام والإجازات: وقت الدوام والسماح للتأخير والعطل والأرصدة والتراكم والترحيل والأجزاء اليومية والاعتمادات تُعتمد من المؤسسة. القيم الحالية أمثلة وسياسات تطوير موثقة، وليست سياسة قانونية مفترضة.
- البيانات الوظيفية: مدير واحد للقسم، قسم ومسمى حاليان للموظف، وسجل تغييرات بالتدقيق. تعدد المديرين والمسميات المتزامنة أو سجل انتقالات وظيفية مستقل يحتاج تحديدًا من المدرب وفق الصفحة 13.
- الصور والمستندات و2FA اختيارية حسب النطاق. التصدير كان اختياريًا في PDF الأصلي، لكن المدرب طلب PDF وإكسل صراحة في ١٩ تشرين الأول؛ نُفذا الآن وفق التحديث المرتبط أعلى التقرير.
- GitHub مطلوب ضمن تقنية التسليم في الصفحة 4، لكنه مؤجل بطلب المالك؛ لم يُرفع المشروع إلى مستودع خارجي.
- النشر في IIS أو بيئة متفق عليها مطلوب في الصفحة 4. اختُبرت نسخة Production محليًا عبر HTTPS؛ الاستضافة الفعلية وصلاحيات قاعدة الإنتاج والشهادات والنسخ الاحتياطي تحتاج هدف نشر محددًا.
- لم تُعدّل هذه المراجعة كلمات مرور الحسابات الحالية أو بيانات HRMSnew، ولا تتطلب مهاجرة جديدة. الاختبارات تعمل على قواعد مؤقتة مستقلة.

## أدلة التحقق

- PdfRequirementsTests: يفحص SQL المُنفذ فعليًا ووجود OFFSET/FETCH قبل تحميل صفحات البيانات، ويكشف الرجوع إلى استعلام لكل حساب، ويفحص فرز التقرير.
- LoginAndDisplayTests: ٦ نتائج ثم التالية ثم الكل مع 107 نتائج وفلاتر، مع ملخص الأقسام وتقرير الأعداد.
- HttpTests: أخطاء API بالعربية والإنجليزية، إضافة إلى الصلاحيات والحماية وحدود الطلبات.
- BrowserAcceptanceTests: دخول الأدوار الستة واللغتين والحجمين والتنقل بالأجاكس والعمليات الأساسية.

راجع آخر نتائج TRX وتقرير القبول للعدد النهائي؛ نجاح الاختبارات لا يحوّل البنود المؤجلة أو السياسات غير المعتمدة إلى بنود مكتملة.
