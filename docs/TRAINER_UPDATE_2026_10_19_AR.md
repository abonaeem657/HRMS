# تحديث متطلبات المدرب — ١٩ تشرين الأول ٢٠٢٦

نقل المالك عن المدرب طلب تصدير التقارير إلى PDF وإكسل، وحصر الإجازات بالسنوية والمرضية وبدون راتب، وإلغاء وقت الإجازة والمغادرات، واعتماد خيارات بسيطة للبنود غير المحددة. هذا التحديث يتقدم على وصف النطاق السابق في مراجعة ١٥ تشرين الأول.

## ما تغيّر في الموقع

| المكان | الاستخدام |
|---|---|
| التقارير ← الملخص | تنزيل ملخص المؤشرات وجداول الأقسام والحالات والحضور والنشاط المصرح به |
| التقارير ← الموظفون | اختر القسم والمسمى والحالة وتاريخ التعيين والفرز، طبّق الفلاتر، ثم نزّل PDF أو إكسل |
| التقارير ← الحضور | اختر الموظف والقسم والتواريخ؛ الملف يعرض أوقات الحضور والانصراف بتوقيت الأردن |
| التقارير ← الإجازات | تصدير الطلبات المطابقة للمرشحات والقرارات، بالتواريخ دون حقول ساعة للإجازة |
| التقارير ← قرارات الإجازة وأعداد الموظفين | تصدير الملخص المعروض وفق النطاق المسموح |
| سجل التدقيق | التصدير متاح فقط للأدوار التي تستطيع قراءة التدقيق أصلًا |
| تقرير إجازاتي | الموظف يصدّر طلباته وأرصدته فقط؛ تغيير معرّف الموظف في الرابط لا يغيّر صاحب التقرير |
| الإجازات ← أنواع الإجازات | ثلاث بطاقات: سنوية، مرضية، بدون راتب. عدّل عدد الأيام للسنوية والمرضية أو حالة التفعيل ثم احفظ |
| طلب إجازة | نوع الإجازة، تاريخ البداية، تاريخ النهاية، السبب؛ لا وقت ولا مغادرة بالساعات |

أزرار التنزيل تظهر بعد نموذج التصفية. الملف يشمل **جميع النتائج المطابقة للفلاتر المطبّقة**، وليس ستة صفوف الصفحة الحالية. تطبيق الفلاتر أولًا يحدد محتوى الملف. التنزيل لا يبدّل الصفحة، وخطأ التصدير يظهر برسالة في شريط الحالة.

إكسل ملف `.xlsx` فعلي، مع خلايا أرقام ونصوص Unicode، وتصفية وتثبيت صفوف العناوين. النص الذي يبدأ بعلامة صيغة يُحفظ نصًا دون تنفيذ صيغة. PDF ملف فعلي بجداول عربية/إنجليزية واتجاه مناسب؛ لا يساوي زر طباعة المتصفح.

## السياسة البسيطة المعتمدة للتطبيق

- الإجازات: سنوية ومرضية وبدون راتب فقط. الافتراض الأولي للسنوية والمرضية ١٤ يومًا لكل منهما؛ القيم الموجودة في القاعدة تُحفظ، ويمكن تعديلها من الموقع. هذه إعدادات تدريب، وليست ادعاء باستحقاق قانوني.
- الحساب بالأيام التقويمية، شاملًا البداية والنهاية؛ لا خصم للعطل ولا تراكم شهري ولا ترحيل تلقائي ولا أجزاء يوم.
- الطلب المعلق يحجز أيامه، والموافقة تثبت الاستخدام، والرفض أو إلغاء المعلق يعيدان الأيام. الرصيد الحالي للمتابعة ولا يمنع التقديم بسبب تجاوز البدل وحده؛ المتبقي لا يعرض قيمة سالبة. بدون راتب لا يملك بدلًا مدفوعًا؛ تسجل أيامه للمتابعة.
- حساب السنة يفصل الأيام حسب وقوعها في كل سنة عند عبور طلب نهاية السنة.
- مدير واحد لكل قسم، ومسمى حالي واحد للموظف، عام أو مرتبط بقسم. تغيير القسم أو المسمى يُدقق؛ لا جدول انتقالات أو وظائف متزامنة إضافي.
- الأقسام والمسميات تُعطل لحفظ العلاقات والتاريخ. لم تُضف عملية حذف مادي. إذا اشترط المدرب لاحقًا Delete منفصلًا، يبقى هذا فرقًا صريحًا عن عبارة CRUD الكامل.
- قواعد الدوام الحالية مستمرة: توقيت الأردن مع تخزين UTC، فترات متعددة في اليوم، فترة مفتوحة واحدة، ومنع التداخل، وتصحيح مصرح به؛ إلغاء وقت الإجازة لا يلغي وقت الدوام.

## الحفاظ على البيانات

الأنواع القديمة عُطلت دون حذف تعريفاتها أو طلباتها أو قراراتها. لا يمكن استخدامها لطلب جديد ولو أُرسلت أرقامها يدويًا. الطلبات القديمة تبقى في تاريخ الإجازات والتقارير. حقول الوقت التاريخية الموجودة في القاعدة لم تُحذف؛ الطلبات الجديدة لا تملؤها ولا تعرضها صفحات الإجازة. لا تتطلب هذه التغييرات مهاجرة مخطط جديدة.

على جهاز تطوير آخر يمكن تطبيق تعريفات الأنواع وتعطيل الزائد بأمر صريح:

~~~powershell
dotnet run --project HRMS -c Release --launch-profile http -- --seed-reference-data
~~~

الأمر يعمل في Development، يحفظ بدلات الأنواع الموجودة وحالتها، وينشئ النوع المعتمد المفقود فقط. لا ينشئ سجلات حضور أو طلبات إجازة أو حسابات.

## إعداد PDF على خادم التشغيل

إكسل لا يحتاج Excel مثبتًا ولا مكتبة إضافية. إنشاء PDF يستخدم Chrome أو Edge بوضع مخفي على **الخادم** لدعم العربية. يبحث التطبيق تلقائيًا عن Chrome/Edge في مسارات Windows المعروفة، أو يمكن ضبط المسار محليًا:

~~~powershell
$env:ReportExport__BrowserPath = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
~~~

يحتاج حساب تشغيل التطبيق إذن تشغيل المتصفح والكتابة في مجلد الملفات المؤقتة الخاص به، مع خط عربي متاح مثل Tahoma. لا تُرسل التقارير إلى خدمة خارجية. يستخدم كل تصدير مجلدًا مؤقتًا منفصلًا خارج مجلد الموقع ويُنظف بعده. يحد التطبيق إنشاء PDF بعمليتين معًا ومهلة ٤٥ ثانية. حد الملف ١٠٬٠٠٠ صف؛ عند تجاوزه تظهر رسالة لتضييق الفلاتر. عند غياب المتصفح يعيد PDF خطأ إعداد مفهومًا مع استمرار إكسل بالعمل.

## التحقق

اختبارات التصدير تتحقق من بنية إكسل والعربية والأرقام وتخزين النصوص دون صيغ؛ ومن ملف PDF فعلي، وتصدير نتائج تتجاوز حجم الصفحة، ومنع مدير القسم من تصدير قسم آخر، وتقرير الموظف الشخصي، والتنزيل من المتصفح. اختبارات سياسة الإجازة تتحقق من حصر الأنواع، وحفظ تاريخ النوع القديم، ورفض طلب جديد عليه، وعدم حفظ ساعات في الطلبات الجديدة.

نتائج الجولة الفعلية وحدودها مسجلة في `docs/VERIFICATION.md`. التشغيل على استضافة نهائية وGitHub مؤجلان كما اتفق المالك سابقًا؛ إضافة التصدير لا تُثبت إنجاز هذين البندين.

نتيجة التحقق النهائية: **١٠٣ ناجحًا، صفر فشل، صفر تجاوز**: ٥٠ وحدة، ٧ معمارية، ٤٦ تكامل وSQL وHTTP ومتصفح. تحقق القاعدة المحلية أثبت أن الأنواع النشطة هي الثلاثة المطلوبة، وأن الموظفين والحسابات والحضور وطلبات الإجازة بقيت ٢٤ و٦ و٢ و٢ على التوالي.
