# اختلاف قاعدة بيانات الموقع عن المهاجرات — ١٩ تشرين الأول ٢٠٢٦

## السبب المثبت

رسالة الموقع كانت تطلب قاعدة `HRMS`، بينما اتصال المهاجرات في النسخة الحالية يستهدف `HRMSnew`. نجاح `database update` في PowerShell لا يغيّر الحل المفتوح في Visual Studio.

فحص Visual Studio أثبت أن الحل المفتوح كان:

~~~text
C:\Users\us\Desktop\MyFolders\HRMS\HRMS\HRMS\HRMS.sln
~~~

إعدادات Development لتلك النسخة تشير إلى `HRMS`. أما إعدادات النسخة الحالية وUser Secrets بالمعرّف `hrms-local-development` فتشير إلى `HRMSnew`.

## المعالجة المنفذة

- فُتح الحل الحالي `C:\Users\us\Desktop\HRMS\HRMS.sln` في Visual Studio، وعُيّن `HRMS\HRMS.csproj` مشروع تشغيل، بعد التحقق من حفظ كل المستندات وتوقف المصحح.
- أُضيف `scripts/run-local.ps1` ليحدد مشروعه من مكان البرنامج النصي، ويشغّل Development على LocalDB/HRMSnew بإعدادات خاصة بعملية التشغيل فقط.
- يطبع التطبيق في Development مجلد المشروع واسم القاعدة عند البدء؛ لا يطبع كلمة مرور أو سلسلة اتصال.

يمكن تشغيل النسخة الحالية من أي مجلد بالأمر:

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\us\Desktop\HRMS\scripts\run-local.ps1"
~~~

ثم افتح `http://localhost:5014/Account/Login`. أوقف تشغيل التطبيق الآخر إذا كان يستخدم المنفذ نفسه. يتيح البرنامج النصي تحديد `-Port 5015` أو اسم قاعدة محلية مختلف عبر `-DatabaseName` عند الحاجة.

ومن Visual Studio افتح الحل الحالي واضغط F5. في مخرجات Development يجب أن يظهر مجلد النسخة الحالية واسم `HRMSnew`.

## نتائج التحقق وحدودها

- شُغّل البرنامج النصي فعليًا على منفذ مؤقت، وأكد سجل التطبيق مجلد النسخة الحالية واسم `HRMSnew`.
- صفحة `/Account/Login` أعادت HTTP 200 واحتوت نموذج تسجيل الدخول. أُوقف مضيف الفحص بعد الانتهاء، دون إيقاف Visual Studio.
- فحص قراءة للقاعدة الحالية نجح: ٢٤ موظفًا، ٦ حسابات، سجلّا حضور وطلبا إجازة. لم تُحذف قاعدة أو سجلات، ولم تُغير كلمات المرور أو المهاجرات.
- نجح ٢٩ اختبار HTTP للصفحات والصلاحيات وحدود الطلبات، دون فشل أو تجاوز. نتائج TRX في `artifacts/runtime-check/test-results`.
- لم تُجرب كلمة مرور حساب مستخدم حالي؛ نجاح عرض نموذج الدخول ليس ادعاءً بنجاح المصادقة بذلك الحساب.

اقتراح إعادة المحاولة الآلية في رسالة EF عام؛ إعادة المحاولة لا تصلح اختيار اسم قاعدة غير المقصود.
